To commit the running container `ubuntu_latest` into a new image named `official:nautilus` on **Application Server 2 (`stapp02`)**, follow these steps:

### 1. Verify the Running Container

You are already logged into `stapp02` as `steve`. Confirm the container name and ID:

```bash
docker ps

```

*(You should see `ubuntu_latest` listed as running).*

---

### 2. Create the Image using `docker commit`

Run the `docker commit` command specifying the container name (`ubuntu_latest`) and the target image name and tag (`official:nautilus`):

```bash
docker commit ubuntu_latest official:nautilus

```

---

### 3. Verify the Image Creation

Check that the new image exists in your local Docker registry:

```bash
docker images

```

**Expected output:**

```text
REPOSITORY   TAG        IMAGE ID       CREATED         SIZE
official     nautilus   <image_id>     4 seconds ago   ...

```

Once verified, click **Check** on the task panel to submit your work.
