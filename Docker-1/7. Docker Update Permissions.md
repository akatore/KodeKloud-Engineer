User `rose` is not able to run docker commands on `App Server 3` in Stratos DC, make the required changes so that this user can run docker commands without `sudo`.

To allow user **`rose`** to run Docker commands without `sudo` on **App Server 3 (`stapp03`)**, you need to add `rose` to the `docker` user group.

Here are the step-by-step commands to complete this task on **`stapp03`**:

---

### Step 1: Log in to `stapp03`

From `jump-host`, complete your login to `stapp03` with the user `banner` (Password: `BigGr33n`):

```bash
ssh banner@stapp03

```

---

### Step 2: Add `rose` to the `docker` Group

Run `usermod` with `sudo` to add user `rose` to the `docker` group:

```bash
sudo usermod -aG docker rose

```

*(If the `docker` group does not exist for any reason, create it first using `sudo groupadd docker`, then re-run the `usermod` command above.)*

---

### Step 3: Verify the Changes

Check that user `rose` belongs to the `docker` group:

```bash
id rose

```

**Expected output:**

```text
uid=... gid=... groups=...(rose),...(docker)

```

---

### Step 4: Test Docker Access as User `rose`

Switch to user `rose` and test running a Docker command without `sudo`:

```bash
sudo su - rose
docker ps

```

If `docker ps` outputs the container headers without a permission denied error, click **Check** on the lab interface to submit the task.
