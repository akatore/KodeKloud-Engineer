The Nautilus DevOps team is conducting application deployment tests on selected application servers. They require a nginx container deployment on `Application Server 1`. Complete the task with the following instructions:

1. On `Application Server 1` create a container named `nginx_1` using the `nginx` image with the `alpine` tag. Ensure container is in a `running` state.

```
docker run -d --name nginx_1 nginx:alpine
```

```
[tony@stapp01 ~]$ docker run nginx:alpine  --name nginx_1 
/docker-entrypoint.sh: exec: line 47: illegal option --
```


The issue is the position of the `--name` flag in your command.

# ⭐⭐⭐
In Docker, options/flags for the `docker run` command must come **before** the image name. Anything specified **after** the image name is treated as a command passed directly into the container itself (in this case, passing `--name nginx_1` to the Nginx entrypoint script, which caused the entrypoint error).

### Correct Command

Place `--name nginx_1` before the image `nginx:alpine`:

```bash
docker run -d --name nginx_1 nginx:alpine

```

### Explanation of flags:

* `-d` (detached mode): Runs the container in the background so it stays running and doesn't block your terminal prompt.
* `--name nginx_1`: Assigns the name `nginx_1` to the container as requested by the task.
* `nginx:alpine`: Specifies the Docker image and the `alpine` tag to use.

After running this, you can verify it is running with:

```bash
docker ps
