# You teach best what you most need to learn.

As per recent requirements shared by the Nautilus application development team, they need custom images created for one of their projects. Several of the initial testing requirements are already been shared with DevOps team. Therefore, create a docker file `/opt/docker/Dockerfile` (please keep `D` capital of Dockerfile) on `App server 1` in `Stratos DC` and configure to build an image with the following requirements:

a. Use `ubuntu:24.04` as the base image.

b. Install `apache2` and configure it to work on `5002` port. (do not update any other Apache configuration settings like document root etc).

To write a valid Dockerfile for this task, you need to fix a few syntax issues:

1. **Commands must start with instructions:** Commands like `apt update` or `sed` must be prefixed with `RUN`.
2. **Match the task requirements:**
* Port requirement is **`5002`** (not `3002` or `8080`).
* Clean up extra non-Apache commands (like Python/pip/uvicorn) that aren't needed for this task.


3. **Keep Apache running:** In Docker, services started with `service apache2 start` exit immediately. Use `apache2ctl -D FOREGROUND` in `CMD` to keep the container running.

---

### Correct `Dockerfile` Content

Create or edit `/opt/docker/Dockerfile` on **App Server 1 (`stapp01`)**:

```dockerfile
FROM ubuntu:24.04

# Install Apache2
RUN apt-get update && apt-get install -y apache2 && rm -rf /var/lib/apt/lists/*

# Configure Apache to listen on port 5002
RUN sed -i 's/Listen 80/Listen 5002/' /etc/apache2/ports.conf && \
    sed -i 's/<VirtualHost \*:80>/<VirtualHost \*:5002>/' /etc/apache2/sites-available/000-default.conf

# Expose port 5002
EXPOSE 5002

# Run Apache in the foreground to keep the container alive
CMD ["apache2ctl", "-D", "FOREGROUND"]

```
